# Долговая нагрузка домохозяйств Казахстана, 2021–2024

Команда DataX. Авторы: Тариелова Алия Тариеловна, Ырысбеков Жаныбек Ырысбекович, Рахимбекова Салия Элнуровна, Джанболотов Кубат.

## Что сделано

Синтетические микроданные БНС: форма Д-004 «Бюджеты домохозяйств» (раздел 2 «Заёмные средства»,
доходы, расходы) + Д-008 (состав семьи). Собрана панель «домохозяйство × квартал»:
12 000 семей × 16 кварталов = 192 000 наблюдений, проверена полнота соединений.

Основные описательные результаты:

- доля семей, взявших новый кредит за квартал: 3,4% (2021) → 5,0% (2024); выплачивающих кредит: 23,6% → 28,3%;
- цель кредита — чаще всего товары длительного пользования (53%); источники: банки ~69%, МФО 4% → 8%, частные лица 21% → 13%;
- выплаты по долгам / доход у платящих: 34% у беднейших 20% против 9% у богатейших 20%;
- доля семей с кредитом по регионам — от 4% до 54%, почти не связана с медианным доходом региона;
- структура дохода: зарплата 61% → 67%, пенсии 21% → 16%.

## Структура

```
src/config.py             пути, расшифровки кодов (цели 2.1, источники 2.2, 23 вида доходов, регионы)
src/01_build_panel.py     панель «домохозяйство × квартал» 2021–2024 → data_processed/ (не в git)
src/02_descriptives.py    описательные таблицы → results/t0–t8
src/03_figures.py         графики → figures/
src/04_presentation.py    слайды → presentation/ (все числа из results/)
run_all.sh                весь пайплайн (~1 минута)
```

## Запуск

```bash
pip install -r requirements.txt
DATATHON_DATA=/path/to/synthetic_microdata_2021-2024_20260921 bash run_all.sh
```

По умолчанию данные ищутся в `../../synthetic_microdata_2021-2024_20260921` относительно репозитория.
Инструменты: Python (pandas, matplotlib).
